# DVD BATTLE

Godot으로 만든 한국어 전략 자동 전투 게임입니다. 현재 공개 소스는 **V2 프리뷰 · 드래프트 핫픽스**입니다.

## 실행

1. 검증에 사용한 Godot 버전은 **4.7.2**입니다.
2. 저장소를 내려받고 Godot에서 `project.godot`을 가져옵니다.
3. 프로젝트를 실행합니다. 홈에서 조합 대전, AI 대전, 거점 장악, 데스매치, 배틀그라운드를 선택할 수 있습니다.

기본 화면은 1600×900, 렌더러는 GL Compatibility입니다. 캐릭터 26명, 전장 21개, 아이템 28개가 포함되어 있습니다. 도감에서 실제 규칙으로 스킬을 시연하고 개발자 실험실에서 전투를 관찰할 수 있습니다.

## 드래프트 핫픽스

- 공개 지형의 사격 통로·장애물·엄폐·우회 거리와 치유 구역을 평가합니다.
- 거점전에서는 과반 확보, 분산 수비, 증원 이동과 지원 능력을 비교합니다.
- 최신 26인 데이터의 회복·보호막·정화·치유 차단·피해 유형을 반영하고 5,700경기 보정표를 다시 생성했습니다.
- 같은 평가 예산의 중간 픽 9개 조건에서 탐색 깊이가 2→4로 늘었습니다. 폭을 줄여 깊이를 확보하므로 전수 탐색은 아닙니다.

## 검증과 남은 제한

원본 소스에서 기능 검사 41종(35,752개), 화면 검사 7종(647개)을 통과했습니다. 독립 냉시작 285쌍의 결과가 모두 일치했습니다.

사전 고정한 마지막 픽 54상황·216경기의 평균 승점은 54.63%→57.41%였습니다. 거점전 전체는 변화가 없었고 5인 팀 조건은 −2.78%p였습니다. 솔로 첫 픽 니트로 편중 목표는 **HOLD**입니다. 전체 드래프트 승률 향상이나 정식 V2의 모든 목표 달성을 의미하지 않습니다. 계산 시간도 증가했습니다.

자세한 범위와 수치는 [검증 요약](docs/VALIDATION_SUMMARY_KO.md)을 확인하십시오.

## 개발 자료

- `scripts/`, `scenes/`, `shaders/`, `assets/`: 게임 소스와 자산
- `tests/`: 기능·화면 회귀 검사
- `tools/calibration_v2/`: 드래프트 보정 생성기
- `tools/telemetry_v2/`: 전투 측정 도구
- `tools/release_v2/`: 기존 개발 환경의 배포 검증 도구

`export_presets.cfg`와 일부 개발 도구에는 원래 개발 환경의 엔진·템플릿 경로가 남아 있습니다. 직접 빌드할 때는 해당 경로를 자신의 환경에 맞추어 설정하십시오. 일부 검증 도구는 별도의 로컬 QA 도우미를 사용합니다. 완성된 실행 파일과 로컬 측정 원자료는 이 소스 커밋에 포함하지 않았습니다.

이 공개 저장소는 로컬 검증 커밋 `29331c1cb1792fb53e5178ee89524945bcc7b185`에서 만든 소스 사본입니다. 게임 런타임 195개 파일은 원본과 바이트가 같습니다. 로컬 프로필·환경 목록이 있는 과거 이력과 측정 보고서는 공개하지 않았으며, 필요한 고정 회귀 입력 `reports/regression_cases_14.json`은 유지했습니다. 공개용 안내·제외 규칙을 추가하고 문서의 개인 사용자 경로를 일반 예시로 바꿨습니다. [소스 출처와 파일 해시](SOURCE_PROVENANCE.json)에 변경 범위를 기록했습니다.
